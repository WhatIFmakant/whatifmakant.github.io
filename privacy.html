Privacy Policy

Last updated: 25 November 2026

YouTube Autopilot is a personal tool run by the owner of the YouTube channel WhatIFmakant. It is not offered to the public, and the only Google account that uses it is the channel owner's own.

What data the app accesses

With the channel owner's permission (Google OAuth), the app uses the YouTube Data API to upload the channel's own videos, set their titles, descriptions and publish times, and read the status of those videos.

How the data is used and stored

  • The login token is stored only on the owner's own computer.
  • No data is sold, shared with third parties, or used for advertising.
  • No data from other YouTube users is collected.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used; see the Google Privacy Policy and YouTube Terms of Service.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: contact the channel via youtube.com/@whatifmakant.
